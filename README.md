# OpenAgent

LLM orchestrator with tools, agents, and memory.

## Getting Started

```bash
# Install dependencies
cd server && npm install
cd ../web && npm install

# Start development
cd server && npm run dev   # API server on :3099
cd web && npm run dev      # Frontend on :5173
```

## API Documentation

Interactive API docs (Swagger UI) are available at **[/docs](http://localhost:3099/docs)** when the server is running.
