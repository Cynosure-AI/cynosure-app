# Homelab

- **Hardware:** Raspberry Pi 5 (8 GB) mit NVMe-SSD, im Vorzimmerschrank
- **Statische IP:** 192.168.1.20
- **Dienste:** Home Assistant, Pi-hole, Vaultwarden (Bitwarden-kompatibel), Uptime Kuma
- **Router:** Magenta Kabelmodem im Bridge-Modus, dahinter eine FritzBox 7590

## Zugriff von außen
- Nur über Tailscale, keine offenen Ports
- Home Assistant App am Handy über Tailscale

## Wartung
- Updates jeden ersten Sonntag im Monat
- SD-Karte als Notfall-Boot liegt in der Schublade beim Router
